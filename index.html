How readiness is scored: Each work item carries an Estimation Marks score (quantity take-off, material upload, labour upload) and a Contracts Marks score (contractor finalization, LOI, work order approval), both out of 100. Risk status compares each item's Activity Start Date against today and its readiness — items starting soon (or already past due) without complete estimation/contract sign-off are flagged Critical or Slipping.

Connecting live data: Paste the Code.gs script into your Google Sheet's Apps Script editor (Extensions → Apps Script), deploy it as a web app (Execute as Me, Access: Anyone), and paste the resulting URL into the banner at the top of this page. The dashboard will then poll your live sheet every 5 minutes, and you can force an immediate check anytime with "Refresh Live Data." If the live source is ever unreachable, this snapshot is shown automatically as a fallback.
